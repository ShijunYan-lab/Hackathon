# A — 独立可玩验证场景

在 Godot 中打开 `game/project.godot`，F5 当前默认启动 `res://tests/a_combat_demo.tscn`，T 切换另一张森林测试地图。也可以选中 `.tscn` 按 F6 独立运行。

| 控制 | 作用 |
|---|---|
| WASD | 移动 |
| 按住 Shift + WASD | 奔跑，播放 sprint 帧 |
| Space | 朝移动方向闪避，没按方向时沿上次移动方向闪避；短暂无敌仅在 MOCK 测试中生效 |
| 鼠标左键 | 朝鼠标方向普通攻击 |
| 1 / 2 | 切换两种不同贴图的测试武器：剑/斧 |
| E | 靠近 NPC 触发对话信号（测试场仅打印信息） |
| T | 切换庭院和森林测试场 |
| R | 重启测试场（**不等于**赛道回退） |

**这是离线 MOCK 原型，不是完整游戏、不是 B 的 LLM Agent、不是 C 的真实后端。** 每 4 秒给商人、医师、护卫注入规则生成的测试任务，只为验证 NPC 可移动、护卫可攻击、任务会报告；它不会真的记忆学习。世界中显示的是测试人物、测试武器 ID，不是 C 创建的 ItemState。

D 集成到正式地图时只实例化 A 的 Player / NPC 场景，连接既定信号，不要把 `a_combat_demo.gd` 的模拟扣血和定时任务复制到正式游戏。若 D 已经实现正式 `game/main.tscn`，请保留 D 的主场景，不要用 A Demo 覆盖。
