# 像素美术 · 48×64 版

当前运行素材由三类来源组成，均已保存到工程；运行时不下载或生成图片。

- `references/`：从用户指定的 D:\google_download 复制的五张原始参考图，原文件未修改。原名、SHA-256 见 `references/SOURCES.json`。
- `characters/`：由 `build_reference_actors.gd` 在 Godot 中裁切、去除设定图背景并按最近邻适配。男女玩家图集各 384×256，8 列×4 行，单帧严格 48×64；15 张 NPC 图集各 576×64，12 列，单帧严格 48×64。
- `painted/`：本轮通过内置 ImageGen 生成的建筑、自然物件和细节原始图集。素材路径及提示规格见 [PROMPTS.md](painted/PROMPTS.md)。
- `environment/`：`build_environment.gd` 切分和适配的 9 种建筑、12 种自然/集市物件、16 种细节物件，以及 Godot 绘制的 192 个地形变体和其他小物件。
- `pixel/`：第一版 Godot 绘制素材。当前仅缺少新版本的物件（例如路灯）、地形边缘图集继续使用；旧玩家图集不再使用。

玩家行顺序：下、左、右、上；第 0 列待机，1–6 列行走，7 列备用。第五张参考图只提供静态方向图，行走采用原图像素的轻微步幅/起伏变形。NPC 列 0–2 待机、3–6 行走、7–11 攻击，取自参考动作图。主场景展示待机和短距离行走，攻击帧供 A 接入，当前没有伤害逻辑。

“原图一致”的实现边界：保留原图的角色设计和像素颜色，没有另造一套角色；大图缩小到 48×64、去背景、镜像方向及补充行走必然改变像素，不能称为与大图逐像素完全相同。原图和可复现裁切源均保留，便于继续微调。

导入默认 Nearest。输出的游戏图片有透明通道。中文字体来自操作系统，没有复制商业字体文件。
