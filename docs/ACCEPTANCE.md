# 验收清单：真实通过后才打勾

公共协议测试仅是底线。以下是功能验收，由责任人写出 commit、seed、步骤、真实输出和限制。
没有跑过就不勾，不用“模型说应该可以”代替。

## 一、可以玩的游戏
- [ ] A/D：WASD移动、攻击、闪避与碰撞正常；中文聊天输入不操控角色。
- [ ] A/C：同一attack_id+target_id只扣一次血；任意已生成NPC可被攻击。
- [ ] C/D：NPC死亡后不再交流/接任务，切图和存档加载不复活。
- [ ] A/C/D：移动/采集任务有实际过程，完成前不发放资源。
- [ ] C：物品只有一个持有人；生成装备属性由同一规则计算。
- [ ] C/D：同seed的初始规则数据一致，不同seed可有不同人物组合。
- [ ] B/C：NPC的谣言、亲见和推测可区分，未知角色不自动知晓凶手。
- [ ] B/C/D：至少一次非固定自然语言对话引起后续真实Agent行动。
- [ ] B/C：组织合作双方有独立同意记录，不由玩家一句话自动结盟。
- [ ] D：live / fallback / mock 标识准确，模型超时不冻结界面。

## 二、自我进化评审 P0
- [ ] C：首轮前保存S0/P0，记录场景/代码/配置/模型/固定提示词版本。
- [ ] A/C：首轮是一项完整任务，可成功/失败/超时，不是一段预写动画。
- [ ] C：交付数量和费用可追溯实际事件，前端不能自报分数。
- [ ] B/C：第一次结束自动learn，source_run_id重复不会学习两次。
- [ ] B：策略只依据当前profile和合法动作，不根据run_number写死。
- [ ] C：第二轮同S0；敌人、货物、资金、能力和随机状态未偷改。
- [ ] D：两次显示实际货物交付率、费用、耗时；缺数据明确未测。
- [ ] B/C/D：能展示新旧参数、经验与来源；不只一句“变聪明”。
- [ ] C：首轮结果已经封存，第二轮不会覆写第一次成绩。
- [ ] C/D：恢复V0会恢复Q、经验检索与缓存，并加载S0，未来记忆不泄漏。
- [ ] A/C/D：回退时旧任务/迟到请求不会污染新世界；可再次执行V0检查。
- [ ] 全员：两轮中未人工改代码、参数、提示词、模型或难度。

## 三、反作弊/稳定性验证
- [ ] C：同request_id重试不重复付款、执行任务、创建世界或学习。
- [ ] C/D：非法流程（未完成首轮就二跑、运行中再开）被明确拒绝。
- [ ] B/C：无来源记忆、错误角色ID、过期profile被拒绝。
- [ ] B/C：护卫无钱/不可用不在合法选择中，不能生成免费护卫。
- [ ] C：场景hash不一致不下“改善”结论，显示不可比较。
- [ ] D：MOCK报告无实测数字；不存在虚构的固定提升百分比。

## 四、交付
- [ ] C/D：从干净Windows环境启动；不依赖开发者本机绝对路径。
- [ ] D：合法素材来源、代码/密钥边界、运行命令和已知限制写明。
- [ ] D：两次完整运行实际录屏保留；真人现场演示另做准备。
- [ ] D：项目说明三行进化说明填实测数据，不填例子中的数。
- [ ] D：提交前检查链接权限、下载结果、回执和备用包。
