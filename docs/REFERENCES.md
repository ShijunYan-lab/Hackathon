# 官方参考与来源说明

本包产品范围、分工、接口和初始参数是项目约定，不是引用外部产品能力的结论。
赛道要求来自用户在本次对话完整提供的说明；截止时间沿用用户确认的 2026-11-15 08:00 UTC+8。
原团队手册在 archive 中保留其官方参考。本次额外核对：

- [R1] Godot 4.5：版本管理、.godot 缓存、文本换行与 LFS。
  https://docs.godotengine.org/en/4.5/tutorials/best_practices/version_control_systems.html
- [R2] GitHub：忽略文件；已跟踪文件需要先取消跟踪。
  https://docs.github.com/en/get-started/git-basics/ignoring-files
- [R3] GitHub：将本地代码加入远程仓库。
  https://docs.github.com/en/migrations/importing-source-code/using-the-command-line-to-import-source-code/adding-locally-hosted-code-to-github
- [R4] Godot 4.5.2 Standard 与同版本导出模板归档。
  https://godotengine.org/download/archive/4.5.2-stable/
- [R5] 本次保留的 Uvicorn 与 Pydantic 固定版本元数据。
  https://pypi.org/pypi/uvicorn/0.48.0/json
  https://pypi.org/pypi/pydantic/2.13.5/json
