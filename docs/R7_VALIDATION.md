## 运输实测

本次相同世界起点与冻结配置下：

| 指标 | 第一次 direct | 第二次 escort |
|---|---:|---:|
| 实际交付 | 4/10 | 8/10 |
| 交付率 | 40% | 80% |
| 用时 | 10.100 秒 | 10.281 秒 |
| 花费 | 0 金币 | 5 金币 |
| 商人生存 | True | True |
| 达到80%成功阈值 | False | True |

本场景使用明确标记 fallback 的规则价值学习，未冒充实时 LLM 推理。系统按第一轮真实奖励更新 direct 价值，第二次从相同 S0 重新选择策略，实际执行护卫付款、移动与战斗。回退恢复完整基线，再在 Godot 中执行回退验证。

这是一次实测案例，不保证所有新种子或所有随机世界都改善。此前排错试跑曾出现两轮均失败，修复了普通世界自卫取消评测运输、面板暂停角色、随机护卫武器和人群阻塞等问题；最终冻结配置在新会话开始前建立，两次之间没有改代码、参数或提示词。护卫的装备、HP、价格都包含在第一次保存的 S0，第一轮同样可选择护卫。

## 14项范围与验证对应

1. 雇佣与履约：免费/付费、余额验证、幂等付款、持续跟随、解除与存档；真实客户端验证自由对话后跟随移动中的玩家。
2. 因果事件与传播：袭击事实、目击者、报案、转述、守卫响应、托管赏金；单测通过。
3. 任务真实性：真实实体、可用物品、地标、收件人；交付完成才和解。世界导演可提出送货、救助、采集和有证据的讨伐。
4. 旅行手记：过滤流水账；合并玩家可见记录，不显示原始坐标和内部来源ID；截图验证。
5. UI：工坊返回行囊、设置/存档返回上级、背包关闭；引擎实际验证。
6. 双向交易：实际库存、NPC余额、买卖、议价、币栈投影和拆分赠送；资金/库存守恒测试。
7. 守卫与安全区：两处聚居地、四名初始守卫，死亡后新身份补充；野怪自然刷新排除安全范围。
8. 精英与经济：增强精英、较好真实掉落、持续刷新概率、稀有宝箱装备、提高装备价格。
9. 战斗响应：本地动画立即开始，后台模型只提议；队列剔除失效命中/到达报告；游玩测试动画启动小于50ms。
10. 资源：草药/木材/石头/铁矿实际拾取、耗尽、世界时间再生与提交任务。
11. NPC生活：真实移动采集、拾取材料、邻近买卖、制作武器和药品、购药服药、消耗材料修理；身体与到达结算接通。
12. 记忆与关系：事实事件来源；复用外观不继承原角色传记，新守卫不继承死者对话。
13. 美术：提取158个素材区域，记录在 manifest.json；接入守卫动画、精英、资源、物品、箱子和装备展示；未执行图中文字。
14. 交付：独立源码 ZIP、含运行环境的 Windows ZIP、启动/检查脚本、交接和本报告。

## 实际边界

- 给定精英图只有单姿态，使用静态素材配合实际移动、受击和淡出；没有声称原图包含完整逐方向动画。
- 自由语言仍受模型正确性和网络影响；断网规则模式不具备任意语言理解。事件由受支持的基础动作组合，模型不能生成并执行新程序代码。
- 后台快速身体/生计策略与模型提议分别标记；完整 NPC 群体并非每帧都调用模型。
- Godot 在受限测试环境中报告无法读取 Windows 系统根证书库。游戏客户端只调用本机 HTTP；真实外部模型由 Python HTTPS 调用，并已成功验证。没有把这条环境日志隐藏成零引擎消息。
- pytest 有一条第三方 Starlette/AnyIO 弃用警告，不影响199项测试通过。
- 未做第二台电脑、手柄、音频、美术全方向补帧或长期多人联机验收。Windows包是本地引擎+源码启动，不是声称已经独立导出的发行 EXE。
