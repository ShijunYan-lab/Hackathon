# 可直接复制到团队群

我们使用同一个《未定之境》仓库开发，请分别认领 A/B/C/D：
A 角色与战斗；B NPC记忆与学习；C 世界规则/后端/评测；D 地图UI/联网/集成提交。
每个人回复“姓名 + 岗位”，然后clone仓库，先读README和AGENTS，再打开team目录里自己的TASKS。
把自己的PROMPT内容发给能读取仓库的大模型，让它在自己的职责目录实际写代码。
普通网页聊天看不到仓库时，按PROMPT里的附件清单上传，不要只发一个私有链接。

初版基础协议已经在shared，不能各自改字段或另建路由。需要改接口找C，需要改主场景/地图找D。
每人用自己的feature分支，不直接往main推。完成一个小切片就更新STATUS、给出运行与测试步骤。

最新赛道硬要求：完整任务第一轮→自动学习→同条件第二轮→实测对比→能恢复V0。
这几项优先于更多美术、地图和装备。MOCK只是联调工具，不是实现完成。
