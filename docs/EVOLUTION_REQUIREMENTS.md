# 最新赛道要求：比赛要看什么，我们实际做什么

## 1. 核心区别
“玩家改变世界”是自由度；“NPC 用第一次反馈改善第二次任务表现”才是本赛道要证明的学习。
保留沙盒玩法，但另提供短任务测评入口，不要求评委完整玩十几分钟。

本文件根据用户提供的完整赛事说明制定：
两次均在 11/15 上午第一轮游园会；每次最好 1 分钟内；两次之间只能系统自动学习，
人可以反馈，但不能改代码、参数、模型或提示词；必须说明指标、学习内容和回退。

## 2. 冻结一个测试任务
商人从集市把药材送到翠林接收点，途中存在固定的怪物威胁。
可以直接运送，或使用同样初始资金雇佣一名可用护卫后运送。
两轮都让同一个规则选策函数按当前策略值决定，不能按轮次写死选项。

评审的 NPC 身份/地图/敌人/初始装备/资金/货物相同；
正常游戏依然随机生成，这个固定测试并不固定世界最终剧情。
护卫在两轮开局就存在，能否付费和雇佣规则相同，不在第二轮凭空多给帮手。

## 3. 指标与奖励
主要指标：货物交付率 = 实际送达数量 / 初始数量。
同时展示：任务是否成功、总费用、完成耗时。
首版成功条件建议是送达至少 80% 且商人存活；阈值写入 scenario 配置并在首跑前冻结。
奖励建议：
`reward = delivered_ratio - 0.1 * (gold_spent / initial_gold)`
费用不能超过初始预算；任务超时/死亡未送达记为实际失败，不能选择性丢弃日志。
使用护卫可能更贵或更慢，报告必须同时展示，不宣传所有指标都改善。
值是项目定义的任务评分，不是外部通用智能评价。

## 4. 学习什么
给 direct 与 escort 分别维护一个价值 Q，依据实际任务反馈更新已经执行的动作：
`Q_new = Q_old + alpha * (reward - Q_old)`。
可用起始值 direct=0.6、escort=0.5、alpha=0.8，作为公开的初始设计值，
不是实际跑出的成绩，也不能在两次之间人为修改。
首次失败可能降低 direct 的值，下一轮因此尝试 escort。一次失败并未证明护卫一定成功；
只有第二次真实执行才产生护卫效果的证据。
如果首跑成功或第二次没有改善，展示真实情况，不能伪造结论。

新增经验记录应明确：哪个任务、选了什么、观察到什么结果、依据哪些事件。
LLM 可以总结已经发生的事实，但不得编造“使用护卫一定能避免伏击”的因果证明。
编年史的来源链是可追溯系统记录，不等于做过严格因果实验。

## 5. 公平的两次运行
1. 建立评测会话，保存世界初始快照 S0 与学习状态 P0；冻结场景配置和代码/模型/提示词版本。
2. 首跑从 S0 + P0 开始，完整到达/失败/超时后结算真实结果。
3. 系统自动调用学习模块，保存 P1、差异、来源；UI 不提供手调参数按钮。
4. 再跑从 S0 + P1 开始；不继承清掉的敌人、钱、护卫付款结果、装备、任务进度。
5. 报告展示两次原始指标、策略选择与经验差异。
6. 回退到 S0 + P0，可再执行检查；不把回退操作混成新的学习过程。

使用相同种子不足以控制一切：保存实体状态、资源、怪物生成时间表和随机数状态。
用场景快照/配置 hash 比较条件；输入任务的模型名/固定提示词 hash、代码 commit、预算也入日志。
战斗使用同一物理与伤害规则；若只能近似复现，说明边界，不声称逐帧完全可重复。
不允许第一轮设高伤害，第二轮偷偷换低伤害。

## 6. 要回退的不止 Q 值
回退学习 profile：Q 值、策略版本、新增经验的检索资格、检索缓存/摘要和其他学习派生状态。
其他 NPC 若在评审轮中也学习，整套相关 profile 都要恢复；最简单是评审只启用被测商人的学习。
审计日志只追加、不删，但 V0 不能读取未来 V1 的经验。异步任务须取消或作废。
本版评审学习集合定义为 `LearningProfile`（字段见 shared/evaluation_protocol.py）。
不要只把 UI 文案从 V1 改回 V0。

## 7. 单次节奏与验收
目标每次 20–45 秒，仅是设计预算，实际需实测。LLM超时使用真实规则学习时如实标为 fallback。
规则学习可满足赛道，但不能声称当前调用了 LLM。纯 MOCK/缓存回放不能当现场学习。
先反复独立重置测试，记录实际成功率和失败案例；不能只保留最好的一对。
现场展示一对实验只证明该场景里的改善，不外推所有玩家与随机地图。

## 8. 提交三行说明模板
比什么：同一药材运输任务，货物交付率 V0【实测】→V1【实测】，同时报告费用与用时。
学到了什么：根据首轮事件【真实ID】更新已执行策略价值，保存新增经验【真实ID】与版本差异。
怎么回退：恢复首轮前 LearningProfile 和世界初始快照，保留审计日志但隔离未来经验。

## 9. 与旧方案的关系
正常探索、任意 NPC 可受攻击、随机装备、组织变化仍然存在。
新增的是一套真实可验收的学习证明，不是另做一段“第二次一定赢”的动画。
四人任务中的带 E 编号事项是本轮新 P0，优先于装饰和扩大内容数量。
