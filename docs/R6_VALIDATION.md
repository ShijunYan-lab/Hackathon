- 直接基于用户上传的 Hackathon-main.zip，不假设远程仓库之后没有更新。
- ZIP 提交标记：1e2d84c5a01d2a11454364d398cabd6306449029。
- 本次实际环境：Linux、Python 3.13.5、pytest 9.0.2。
