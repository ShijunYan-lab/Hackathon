# B｜NPC 反馈学习算法说明

## 用什么算法

任务选路采用**情境化多臂老虎机（Contextual Bandit）**的表格价值估计。每个 NPC 有独立的策略表。每个表项 Q(c, a) 记录该 NPC 在情境 c 下选择策略 a 的估计收益。一个完整任务结束后，系统收到一次奖励，用它更新本次尝试的策略。

砍树示例的情境键包含任务、风险档、生命值档和装备。当前沙盒的任务风险档统一为 `high`，生命值达到 16 记为 `healthy`，低于 16 记为 `injured`。情境键不含村庄名称，因此同一个 NPC 在另一村庄遇到相同条件时，可以使用此前的策略值。其他 NPC 有各自的表。

## 从事件到下一次选择

1. **选策**。首次碰到某个任务情境时，初始化捷径 `shortcut=0.650`、河边绕路 `detour=0.450`。选择 Q 值较高的路线。相同值时选河边路线。
2. **执行**。沙盒按路线移动、记录到达与危险事件，并按实际剩余资源结算。相同任务快照中，同一地点的危险样本由任务种子固定。
3. **取得反馈**。用实际成功状态、取得的资源量、损血和耗时计算奖励。奖励限制在 −1 到 1。
4. **更新**。输入 `learn` 后，系统用固定学习率 0.8 更新实际走过的路线，并记录事件 ID、经验和版本。另一条路线保留原值，同一次结果只学习一次。
5. **复跑**。输入 `rerun` 恢复首轮物理条件，导入学到的认知，再调用同一个选策函数。

```text
基础分 = 成功时 0.7，失败时 -0.6
奖励 = clip(基础分 + 0.1 × 资源量 - 0.035 × 损血 - 0.015 × 回合数, -1, 1)
Q 新值 = Q 旧值 + 0.8 × (奖励 - Q 旧值)
```

## 固定种子的两轮实测

使用 seed `20261113`，由默认选中的第一个 NPC 完成砍树。两轮均为本地模拟。

| 指标 | 首轮 v0 | 复跑 v1 |
| --- | --- | --- |
| 实际路线 | 东村 → 道路 → 遗迹 → 森林 | 东村 → 河流 → 森林 |
| 木材 | 2 份 | 2 份 |
| 损血 | 17 | 0 |
| 耗时 | 3 个模拟回合 | 2 个模拟回合 |
| 奖励 | 0.260 | 0.870 |

首轮奖励为 `0.7 + 0.1 × 2 − 0.035 × 17 − 0.015 × 3 = 0.260`。学习后，捷径 Q 值为 `0.650 + 0.8 × (0.260 − 0.650) = 0.338`。复跑时河边路线的初始值 `0.450` 高于 `0.338`，因此被选择。第二轮的收益要等实际执行完才知道，换种子或环境可能得到不同结果。

输入 `rollback` 将世界和认知恢复到输入 `run woodcut` 前的快照。这个例子会恢复捷径 Q 值 `0.650` 和 v0。开局的背景经历和任务开始前已经记住的对话可以继续检索。首轮增加的任务经历与学习记录从可见记忆中撤回，事件仍可用 `events` 查阅。

## 其他入口

| 入口 | 使用的反馈 |
| --- | --- |
| 终端中文问答 | 本机使用 DeepSeek，按身份、性格、目标和个人记忆回答。成功的实时对话会进入当前角色的私有记忆；任务选路的奖励取自任务实际执行记录。 |
| `step` 自主推进 | 按地点维护移动策略值。角色以 15% 概率探索邻近选项，按有事件证据的采集、互动和冲突反馈更新所选行动，学习率为 0.5。 |
| 正式 `transport_v1` | 在可用的 `direct` 与 `escort` 中按策略值选择。由 C 提供真实结算，奖励为 `交付量 / 初始货物量 − 0.1 × 费用 / 初始金币`，学习率使用档案中冻结的 `alpha`。B 返回带事件来源的更新提议，由 C 保存版本和执行回退。 |

查看[本地终端运行手册](B_SANDBOX_README.md)复现两轮。源码入口见 [sandbox.py](sandbox.py) 和 [transport_learning.py](transport_learning.py)。
