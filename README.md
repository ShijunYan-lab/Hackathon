# 未定之境 · The Unwritten Realm

**由智能体驱动的自我演化开放世界。**

《未定之境》是一款以中世纪奇幻世界为背景的像素风开放世界 ARPG，融合自由探索、即时战斗与非线性叙事。你将从一座小镇出发，穿行于森林、营地和遗迹，与沿途的人交谈、交易、合作，也可能产生冲突。

这里的 NPC 拥有各自的人格、目标与记忆。你的帮助、承诺和伤害会留下影响，NPC 也会与其他角色互动、积累经历，并在部分任务中根据反馈调整策略。人物关系、资源和任务随行动变化，让每段旅程拥有不同的走向。

角色成长依靠装备选择、探索收获、行动抉择与战斗技巧，不设置角色等级。

推荐在 Windows 上通过 `Start_Game.bat` 启动。

## 可以体验什么

- **探索与战斗**：探索村镇、森林与遗迹，使用近战或远程武器，通过奔跑、闪避和出招时机应对不同遭遇。
- **自由交谈**：直接输入自己的话，询问身份、打听消息、商议交易或邀请同行，在交流中了解人物与世界。
- **关系与记忆**：NPC 根据自己知道的信息和交往经历作出回应，合作与冲突会影响之后的信任和选择。
- **装备与生活**：拾取物资、采集资源、买卖物品、使用药剂，并管理自己的行囊与装备。
- **任务与世界变化**：接受送货、收集、讨伐等委托。NPC 也能参与采集、交易、购药、制作、维修与探索，具体行动受所在地点、物资和能力限制。
- **反馈学习**：部分任务会根据真实执行结果更新策略价值与经验，支持查看学习前后的表现，并回退学习状态。
- **旅程记录**：旅行手记记录重要经历和已知委托，存档保留世界状态与冒险进程。

## 开始之前

这是带启动器的源码体验版。请先将完整文件夹解压到本机可写入的目录，不要直接在压缩包里运行。

源码版需要：

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 64 位 |
| Python | 推荐 Python 3.11，安装后能在终端中使用 `py` 或 `python` |
| Godot | Godot 4.5.2 Standard，选择 Windows 64 位可执行文件 |
| 网络 | 首次安装依赖需要联网；启用真实大模型时也需要联网 |
| 模型服务 | 可选，使用自己的兼容接口和 API Key |

Python 可从 [Python 官网](https://www.python.org/downloads/windows/) 获取；Godot 可从 [Godot 4.5.2 下载页](https://godotengine.org/download/archive/4.5.2-stable/) 获取。Godot 下载后请先完整解压。

如果拿到的是另行打包、已经附带 `.runtime` 的运行包，启动器会优先使用其中的运行环境。

## 快速启动

### 1. 安装运行环境

在游戏根目录双击 **`Setup_Game.bat`**，等待依赖安装完成。它会在游戏目录内建立独立环境。

也可以在该目录打开 PowerShell，执行：

```powershell
.\Setup_Game.bat
```

### 2. 启动游戏

安装成功后，双击 **`Start_Game.bat`**：

```powershell
.\Start_Game.bat
```

首次启动会导入素材并启动本地世界服务，可能需要等待一段时间。如果弹出文件选择窗口，请选择 **Godot 的 `.exe` 文件**，例如 `Godot_v4.5.2-stable_win64.exe`，不是 `project.godot`。

启动器会记住选择的 Godot 路径，后续通常不必重复选择。启动游戏时请保留启动器终端，结束体验后从游戏菜单退出。

### 3. 创建自己的旅人

在主菜单输入名字、选择男性或女性角色，然后选择是否启用大模型，点击“新游戏”。第一次体验建议新建存档。

如果界面提示本地世界服务正在启动，请等待连接完成；已点击的新游戏会在连接成功后继续。

## 大模型配置（可选）

不启用大模型时，可以体验基础探索、战斗和规则驱动的 NPC 行为。想体验更灵活的自由对话与模型决策，请在主菜单或设置中勾选 **“启用大模型”**，填写以下三项：

| 配置项 | 填写内容 |
| --- | --- |
| API Base URL | 服务商提供的 HTTPS 接口基地址，不要填写完整的 `/chat/completions` 地址 |
| 模型名称 | 你的账号可以调用的模型名称 |
| API Key | 你自己的模型服务密钥 |

例如，使用 DeepSeek 时可填写：

```text
API Base URL：https://api.deepseek.com
模型名称：deepseek-chat
API Key：填写自己的密钥
```

本项目支持兼容 OpenAI Chat Completions 格式的接口。填写后实际与 NPC 交谈，观察界面状态：

- **live**：本次对话使用了真实模型。
- **fallback**：本次使用规则模式，或模型调用失败后降级处理。

配置已应用不等于模型已成功响应，以实际对话状态为准。真实模型需要可用的账号、额度和网络，调用费用按服务商规则结算。

在游戏界面填写的密钥仅供本次后端运行使用，不写入游戏存档；后端重启后需要重新填写。分享项目或截图时，请保留密钥的私密性。

## 基本操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` |
| 奔跑 | `Shift` |
| 闪避 | `空格` |
| 朝鼠标方向攻击 | `鼠标左键` |
| 切换已拥有的近战 / 远程武器 | `1` / `2` |
| 与附近人物、资源、箱子或告示牌交互 | `E` |
| 打开行囊，管理装备、药剂和赠送物品 | `Tab` |
| 查看旅行手记和已知委托 | `J` 或 `F2` |
| 打开地图 | `M` |
| 返回、关闭当前界面或打开暂停菜单 | `Esc` |
| 保存旅途 | `F6` |
| 读取已保存的旅途 | `F7` |
| 打开运输学习评估界面 | `F4` |
| 重试失败的网络请求 | `F9` |

交谈或打开界面时，部分移动和战斗操作会暂时受限。先按 `Esc` 返回，再继续行动。切换武器需要行囊中已有对应武器。

## 第一次游玩建议

### 先认识沿途的人

靠近 NPC 按 `E`，在输入框中自由交谈，例如：

> “你叫什么名字？平时在这里做什么？”
>
> “我想看看你的东西。”
>
> “附近有什么消息？”
>
> “你愿意和我一起去森林吗？”

这些是可以尝试的输入，不是固定剧情指令。不同人物的回应取决于身份、性格、记忆和当前处境；自由语言的理解效果也会受所选模型影响。

### 交易、同行与完成委托

- **交易**：通过交谈提出买卖需求，在对方同意并打开交易界面后查看商品、报价或出售物品。能否交易取决于对方的身份、库存、资金和关系状态。
- **同行**：与 NPC 商议同行条件。有酬金的契约可在旅行手记中查看并付款，支付时需要靠近对方；也可以在手记中结束同行。
- **送货**：先明确接受委托，确认收件人和地点线索。找到收件人后，靠近对方，从 `Tab` 行囊中赠送指定物品。
- **收集与讨伐**：在旅行手记中查看条件，完成后回到委托人附近提交。
- **制作与维修**：留意工坊、材料和装备状态，按界面提示操作；NPC 的制作与维修同样需要真实材料和可用工坊。

人物可能移动，消息也可能只反映对方最后知道的位置。线索不清楚时，可以继续询问人物、地点范围与相关经历。

### 留下自己的旅程

旅行手记会整理重要经历与已知任务。离开前可以按 `F6` 保存，或通过暂停菜单保存并退出；下次在主菜单选择“读取存档”继续。

本机存档与日志位于 **`runtime/`** 目录。备份或升级前，先退出游戏并保留这个目录，避免覆盖已有旅途。

## 体验反馈学习

按 `F4` 可以打开运输学习评估界面，按界面步骤进行首次任务、反馈学习、第二次任务和版本回退。

两次运行恢复相同的初始任务条件，保留自动更新后的策略与经验，比较交付情况、成本、耗时及奖励。也可以查看策略值变化和来源事件，了解反馈如何影响了选择。

学习结果取决于实际任务反馈，不保证每种场景都会改善。普通游玩时按 `F6` 保存旅途；学习评估中的版本回退则按评估界面操作。

## 常见问题

### 启动时提示找不到 Python，或安装依赖失败

确认已安装 Python 3.11，并能在终端中运行 `py -3.11 --version` 或 `python --version`。保持网络畅通后重新运行 `Setup_Game.bat`。主菜单也提供“安装/修复运行环境”入口。

### 找不到 Godot，或首次导入失败

选择 Godot 4.5.2 Standard 的 `.exe` 文件。素材导入失败时，可查看 `runtime/godot-import.log`。确认解压完整，不要只复制启动器或 `game/` 中的部分文件。

### 主菜单一直显示未连接

优先关闭当前游戏，再从项目根目录运行 `Start_Game.bat`。启动器会检查本地服务，并在默认端口被不兼容的程序占用时尝试其他空闲端口。

如果仍然无法连接，在项目根目录打开 PowerShell，执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\release\diagnose_connection.ps1
```

诊断结果和 `runtime/backend.stderr.log`、`runtime/godot.log` 可以帮助定位问题。反馈时附上操作步骤和错误信息，并隐藏密钥。

### 填了 API，NPC 仍显示 fallback

检查是否勾选“启用大模型”，再确认接口基地址、模型名称、密钥、账号额度和网络。实际对话显示 `live` 才说明本次模型调用成功。

### 无法交互、付款或交付物品

先关闭其他界面并靠近目标，确认人物仍在附近，任务已经接受，金币和指定物品充足，再按界面提示操作。
