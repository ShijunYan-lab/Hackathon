# 未定之境 · The Unwritten Realm

一款中世纪奇幻风格的像素沙盒 RPG。你可以探索村庄、森林与遗迹，与人物交谈、交易、接受委托，也可以拿起武器战斗。你的行动会留下记录：人物会记住交往，物品与金币有实际归属，死亡也会成为世界历史的一部分。

**当前为 R6 源码体验版，需要安装 Python 和 Godot，暂未提供独立游戏安装包。** 以下步骤以 Windows 为例。

## 游戏特色

- **探索与战斗**：奔跑、闪避，使用近战或远程武器，寻找宝箱与掉落物。
- **自由输入对话**：询问人物的名字、了解近况，向商人查看商品或议价。
- **装备与交易**：管理行囊、装备武器与胸甲、使用药剂、赠送物品和购买商品。
- **世界委托**：通过交谈发现送货、帮助迷路旅人回去等任务；委托是否出现取决于世界情况。
- **旅途记录**：查看经历与已知委托，保存游戏，下次继续探索。
- **可选 AI 对话**：连接大模型服务，体验模型生成的对话与人物决策，也可关闭模型，以规则模式体验基础玩法。

游戏仍在完善中。目前委托主要为送货和救助，装备槽位的功能也在逐步补全；模型对话受所用服务与网络影响。

## 安装与启动（Windows）

### 1. 准备运行环境

| 工具 | 版本与选择 | 用途 |
| --- | --- | --- |
| Python | **3.11**，安装时勾选 **Add python.exe to PATH** | 运行本地世界服务 |
| Godot | **4.5.2 Standard 的 Windows 版本**，无需 .NET 版 | 运行游戏画面 |

Python 可从 [Python 官网](https://www.python.org/downloads/windows/) 获取；Godot 可从 [4.5.2 下载页](https://godotengine.org/download/archive/4.5.2-stable/) 获取。Godot 下载后先解压，保留整个文件夹。

首次安装依赖需要联网。关闭大模型后，基础玩法不需要连接外部模型服务。

### 2. 下载游戏

在本仓库首页选择 **Code → Download ZIP**，完整解压到新文件夹，再打开它。确认里面有 `Setup_Game.bat`、`Start_Game.bat`、`game` 和 `release` 等文件或文件夹。

不要在压缩包预览窗口中直接启动。更新游戏时请使用新文件夹，保留旧版与存档。

### 3. 安装依赖

双击 **`Setup_Game.bat`**，等待窗口提示 **`Setup complete`**。

它会在游戏文件夹内创建独立运行环境，安装所需组件。首次安装可能需要等待；若出现错误，请先查看下方常见问题，处理后重新运行。

### 4. 启动游戏

双击 **`Start_Game.bat`**。

首次启动若弹出文件选择窗口，请选择解压后的 **Godot 4.5.2 可执行文件（`.exe`）**，不要选择 `project.godot`。启动器会记住这个位置。

启动器会先检查资源，再启动本地世界服务和游戏窗口。首次导入可能需要一些时间，请等待主菜单出现。之后每次游玩，直接双击 `Start_Game.bat` 即可。

## 第一次游玩

1. 在主菜单输入名字，选择角色外观。
2. 初次体验可先不勾选“启用大模型”，使用规则模式。
3. 点击“新游戏”。新角色从旧铁剑、布衣和少量金币起步。
4. 靠近人物按 **E** 交谈，试着输入“你叫什么名字？”。遇到商人时试试“我想看看你的东西”。
5. 按 **Tab** 查看行囊，按 **M** 查看地图，再前往野外探索。人物可能反击、逃离或求助，攻击前请谨慎决定。
6. 结束时按 **Esc** 选择“保存并退出”。下次在主菜单选择“读取存档”。

人物信息需要通过接触逐步了解。商人的货物需通过交易购买，不能像公共宝箱一样直接拿走。送货需将指定包裹赠送给收件人；救助需与迷路旅人交谈，让其实际返回目的地。

## 操作说明

| 操作 | 按键 |
| --- | --- |
| 移动 | **W / A / S / D** |
| 奔跑 | **Shift** |
| 闪避 | **空格** |
| 朝鼠标方向攻击 | **鼠标左键** |
| 切换近战 / 远程武器 | **1 / 2**，需要先拥有相应武器 |
| 与附近人物交谈 / 打开附近公共箱子 | **E** |
| 打开行囊，装备、使用或赠送物品 | **Tab** |
| 打开 / 关闭地图 | **M** |
| 查看手札、已知委托与旅途记录 | **J** 或 **F2** |
| 暂停与菜单 | **Esc**；已有窗口打开时先关闭该窗口 |
| 快速保存 | **F6** |
| 快速读取已记录的保存点 | **F7** |
| 请求失败后重试 | **F9** |

另有 **F4** 运输评测界面，供演示和测试使用，普通游玩无需打开。

菜单、对话和行囊打开时，世界推进会暂停。输入对话或操作界面时，请先结束输入或关闭窗口，再使用探索按键。

## 启用 AI 对话（可选）

在主菜单或游戏设置中勾选“启用大模型”，填写自己所用服务提供的信息：

| 配置项 | 填写内容 |
| --- | --- |
| API Base URL | HTTPS 接口基地址，可能包含 `/v1`；不要填完整的 `/chat/completions` 请求地址 |
| 模型名称 | 你的账号实际可以使用的模型名 |
| API Key | 该服务的访问密钥 |

当前支持 **OpenAI-compatible Chat Completions** 接口。配置后实际与人物交谈，确认界面状态：`live` 表示模型模式，`fallback` 表示规则降级。保存配置成功不代表模型调用一定成功。

使用外部模型需要联网，可能产生服务商收取的费用。对话及相关游戏上下文会发送给所配置的服务，请勿输入敏感信息。菜单输入的密钥只在本次世界服务运行期间留在内存中，不写入存档；关闭服务后，下次需要重新填写。

不配置模型也可以游玩，但规则模式对自由语言的理解更有限，复杂表达可能得不到预期回应。

## 存档、备份与更新

游戏支持主菜单读档、菜单保存及 **F6 / F7** 快捷操作。自由探索期间约每 60 秒会尝试自动保存，但对话、菜单或请求处理中可能延后；退出前建议主动保存。

数据位于游戏目录的 **`runtime/`** 文件夹中，默认世界数据库为 `runtime/playable-r6.sqlite3`。

- **备份**：关闭游戏及本地世界服务后，复制整个 `runtime/` 文件夹。
- **更新**：先备份，再将新版解压到新文件夹。旧存档不保证兼容所有新增玩法；体验完整的新开局内容，建议新建游戏。
- **分享**：分享源码时无需携带 `runtime/`，其中可能包含存档、日志和私人对话。

## 常见问题

### 提示找不到 Python / Python 3.11

确认已安装 Python 3.11，并启用了添加到 PATH 的选项。安装后关闭原窗口，再双击 `Setup_Game.bat`。若电脑有多个 Python 版本，请确认包含 3.11。

### 安装依赖失败

检查网络后重新运行 `Setup_Game.bat`，已有环境会继续使用。若仍失败，请保留窗口中的第一条错误信息。

### 启动时要求选择文件，应该选哪个？

选择解压后的 Godot 4.5.2 Standard `.exe`，不要选择工程文件或 Godot 压缩包。若移动过 Godot 文件夹，重新启动后按提示选择新位置。

### 提示 `old or different service`，或 8765 端口被占用

可能还有旧版本的本地世界服务在运行。回到启动旧服务的窗口，按 **Ctrl+C** 停止，再启动本版。启动器不会自动关闭其他程序；不确定端口由谁占用时，请先保留错误提示。

### 无法进入游戏，或窗口闪退

确认已经完成 `Setup_Game.bat`，且选择的是 Godot 4.5.2 Standard。然后查看 `runtime/` 中的日志：

- `godot-import.log`：资源导入与脚本检查。
- `godot.log`：游戏运行错误。
- `backend.stderr.log`、`backend.stdout.log`：本地世界服务运行记录。

反馈时请说明操作步骤、是否启用模型，并附上第一条错误信息。分享日志前请移除密钥及不愿公开的对话内容。

### AI 没有回应，或显示 `fallback`

检查服务地址、模型名、密钥、账号额度和网络。可以先关闭大模型继续体验基础玩法，连接恢复后再配置。即时战斗反应与部分世界行为本来就由规则处理，并非每个动作都会调用模型。

### 按 2 没有切换出弓箭

角色必须先拥有远程武器才能使用。新角色不会自带全套装备。
