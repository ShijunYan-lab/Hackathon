# 大地图、美术与对话版本 · 2026-11-14

打开 [game/project.godot](../game/project.godot)，Godot 4.5.2 中按 **F5**。不需要启动 Python 或后端。

本版把地图扩到原面积的 4 倍（10240×7168px），两座村庄与大森林可连续步行往返。所有区域解除圆形视野，整个屏幕可见，地图四边仍有空气墙。建筑与环境增补屋顶、石墙、木梁、烟囱、摊货、花盆、柴堆、农田、果园、磨坊、营地、修道院、墓园和河港细节。

男女玩家来自第五张原图；村庄、森林、遗迹共 15 种 NPC 来自前三组动作图及总览，所有帧统一 48×64。保留原图设计，通过裁切、去背景和最近邻适配实现；不是另一套重新生成的角色。缩小、补充行走与方向镜像意味着不能保证与大尺寸原图逐像素相同。

## 操作和验收路线

1. 灰橡镇家门前出发：WASD/方向键移动，Shift 奔跑，V 切换男女外观。
2. 向东找到铜鹿酒馆和霍尔特的铁砧，靠近人物按 E；输入中文后 Enter 或点发送，试用传闻/手艺话题，Esc 关闭。
3. 沿旧王大道过北桥抵达鸦渡镇，找到集市的伊莲娜与院落的玛尔塔。沿南线经过枯井驿站、南桥返回。
4. M 查看行路图。到西南风磨丘看磨坊/麦田，沿河到苇岸渡口看木船和税关。
5. 从村庄北行，路止于林缘；穿行黑枝林地与暮影古林，寻找苔石猎营、断誓堡、暮钟修道院、寂鸦墓园。
6. 检查进入任何区域后都没有圆形黑幕；水岸和地图四边不能越过。
